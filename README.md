# Yellow Static
Single-file Three.js horror game. Upload `index.html` (and `.nojekyll`) to GitHub Pages or any static host and open it.
Controls: WASD move, mouse look, Shift run, F flashlight, E use, 1-9 items. Touch controls appear on phones.
Co-op: Co-op button on the title screen (swap two codes, works across devices).
